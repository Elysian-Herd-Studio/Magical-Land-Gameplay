# 精神回声检查

检查脚本由维护者本地保存，下文的脚本路径对应本地维护快照。

这些脚本使用已有的 Minecraft 1.20.1、Fabric、JOML 与 LWJGL 依赖，进行独立编译和回归，不下载依赖、不调用 Gradle，也不启动 Minecraft。输出目录必须位于仓库之外。

## 时序与渲染挂钩

运行 `run-tests.ps1`，传入 `ClasspathFile`、`JavaBin` 与 `OutputDirectory`。依赖清单为当前平台路径分隔符连接的 JAR 路径，需要包含具名 Minecraft 客户端与 ASM。

- 首次完全遮挡时起波，部分遮挡本身不触发。
- 每 3 秒重新发波；轮廓显现后用 3 秒渐淡，每轮波的起点不会随光团移动。
- 换波后保留上一轮尚未消退的远侧轮廓；首次起波不凭空补出上一轮。
- 暂停、时间回退、视线恢复、无效输入和会话重置。
- 读取实际 GameRenderer 字节码，核对世界深度捕获先于手持物清深度，回声合成先于 HUD。

## 离屏 GPU

运行 `run-gpu-tests.ps1`，传入 `DependencyClasspathFile`、`JdkBin` 与 `OutputDirectory`。脚本从依赖清单选取 JOML/LWJGL，并创建隐藏的 GLFW 上下文。

覆盖严格 OpenGL 3.2 与原生扩展两种模式，验证真实输出像素：

- 轮廓在 1 秒、2 秒后仍有残影，并在显现满 3 秒时平滑消退。
- 新一轮开始时保留上一轮的远侧轮廓，两轮各自使用发波位置。
- 重叠信号取较强者，不相加；重复绘制不累积变亮，贴图色块不会变成轮廓。
- 深度格式、透视相机、局部黑边、深度／模板／alpha 保留、渲染状态恢复及安全跳过。
