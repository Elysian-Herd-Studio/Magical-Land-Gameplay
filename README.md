# Magical Land Gameplay

[English](README_EN.md) | 简体中文

</div>

Magical Land Gameplay 是 [Magical Land（魔法大陆）](https://github.com/Elysian-Herd-Studio/Magical-Land) 的玩法扩展，为小马加入三族能力与成就。

## 玩法

### 三族能力

- **独角兽**：念力出窍、自我悬浮，以及操控工具护卫或采集的御物能力。
- **天马**：悬停、滑翔、回环与横滚，配合拍翼落地保护和碰撞回弹。
- **陆马**：通过震动感知察觉附近的地面活动。

首次进入世界时选择种族，默认通过药水改族。服务器可允许自由改族，并决定角和翅膀是否必须符合种族。详见[种族选择](docs/races.md)与[能力文档](docs/README.md#三族能力)。

### 成就系统

在探索与互动中解锁成就，可在原版进度界面查看。已加入的成就与触发条件见[成就文档](docs/achievements.md)。

## 安装

适用于 Minecraft **1.20.1 / Fabric**。客户端和服务器均需安装：

- Fabric Loader 0.19.1 或更新版本、Fabric API。
- Magical Land Gameplay `0.3.4`。
- Magical Land `>=0.3.6 <0.4.0`，以及 GeckoLib 4.7 或更新版本。

升级时同步更新客户端和服务器。从旧一体包升级时，先移除旧包，再安装 Magical Land 与 Gameplay。

客户端可选安装 Mod Menu，以打开玩法设置页。Magical Land 主模组也可以单独使用。

## 开始使用

- 按住 **R** 打开能力轮盘，选中能力后松开。
- 按 **V** 使用所选能力。按键可在原版控制设置中调整。
- 天马双击跳跃键起降；飞行时按 **Ctrl** 切换悬停与滑翔。
- 安装 Mod Menu 后，从「模组 → Magical Land: Gameplay → 设置」调整能力选项、选择种族或查看服务器规则。

各能力的操作与规则见[文档目录](docs/README.md)。
