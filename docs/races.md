# 种族选择

[文档目录](README.md) → 三族能力 → 种族选择

目前可选择独角兽、天马和陆马。种族决定可用能力，服务器可调整改族与外观规则。依赖版本见[安装说明](../README.md#安装)。

## 选择与改族

首次进入安装了 Gameplay 的世界或服务器时，界面会提示选择种族。可以先关闭，稍后通过能力轮盘左上角的「设置」进入种族页；未选择时不能使用种族能力。原存档升级后也需要选择，系统不会根据旧外观自动决定种族。

选择后，身份跟随该世界内的玩家 UUID 保存。死亡、重连、切换维度和更换外观预设都不会重选；不同世界和服务器各自保存。

默认需要喝完对应的改族药水才能更换种族。三瓶药水位于创造模式的「食物与饮品」分类，首版没有生存配方。管理员也可发放：

```mcfunction
/give @s magicaland_gameplay:unicorn_race_potion
/give @s magicaland_gameplay:pegasus_race_potion
/give @s magicaland_gameplay:earth_pony_race_potion
```

选择或改族时需要站在地上，且没有骑乘、游泳、飞行、睡眠、正在受伤或念力出窍等状态。药水只在喝完并通过服务端检查后生效；中途松手、条件变化或规则不允许时不会消耗。改族成功会播放变身光尘和轻声魔法音效。

独角兽可使用[念力出窍](remote-presence.md)、[自我悬浮](unicorn-levitation.md)和[御物](telekinesis.md)，陆马可使用[震动感知](earth-sense.md)，天马可使用[飞行](pegasus-flight.md)。自我悬浮也支持创造模式，准备期间接管飞行，取消后恢复原版飞行操作。

轮盘显示当前可用或已开启的能力；天马飞行由双击空格触发，不占轮盘位置。松开轮盘选择、V 使用、右键图标关闭对应能力，切换选择保留持续技能。改族清除旧选择，普通规则同步则保留。御物的短按、长按和召回操作见[使用说明](telekinesis.md#轮盘与操作)。

## 外观与能力

默认外观需要符合所选种族：独角兽有角无翼，天马有翼无角，陆马无角无翼。颜色、发型及其他装饰继续使用玩家的外观设置。

角和翅膀通过公共 API 临时覆盖显示，世界渲染、背包和捏脸预览使用相同规则。已保存的外观预设不被改写；回到没有 Gameplay 的世界，或服务器开放自由外观后，会恢复按原预设显示。

服务器可以单独允许自由外观搭配。此时可自由显示角和翅膀，但能力仍取决于服务端保存的种族；给陆马戴角不会获得独角兽能力。

选择独角兽会启用念力出窍。原有 `/magicaland remote_tool revoke <players>` 仍可临时撤回能力，`grant` 可恢复；授权标签不能让其他种族越过身份检查。再次改为独角兽时会重新启用。

## 玩法设置

安装 Mod Menu 后，打开「模组 → Magical Land: Gameplay → 设置」，进入「种族选择」或「种族规则」。

种族规则由当前世界或服务器保存：

- **药水改族**：首次自由选择，之后喝药水更换，默认使用此项。
- **自由改族**：可在选择页随时更换，仍需要满足安全状态。
- **锁定种族**：允许首次选择，之后选择页和药水都不能改族。
- **自由外观**：允许角和翅膀与种族不一致，独立于改族方式。
- **开放种族**：控制可新选或改入的种族，至少保留一族。关闭某一族不会清除已经选择它的玩家身份或能力。

单人世界主人可直接调整规则，不需要开启作弊。多人服务器需要管理员权限；普通玩家可以查看，不能保存服务器规则。规则页先编辑草稿，点击保存后才提交。其他管理员已更新规则时，需要重新读取后再修改。

管理员还可直接指定身份：

```mcfunction
/magicaland race set <players> magicaland_gameplay:unicorn
```

将末尾换为 `magicaland_gameplay:pegasus` 或 `magicaland_gameplay:earth_pony` 可指定另外两族。该命令需要 2 级权限，可越过开放种族与改族方式限制；会先结束出窍、结算携带物品，再检查玩家是否处于安全状态。

## 存档与维护

种族与规则保存在主世界的 `data/magicaland_gameplay_races.dat`，按玩家 UUID 记录。种族 ID 使用命名空间形式；每位玩家预留 `Progress` 数据位置，暂未接入经验或成长玩法。未知但格式正确的旧种族 ID 会保留，由管理员决定如何恢复，不自动分配另一族。

服务器校验改族目标、规则版本、权限和玩家状态。客户端只显示服务端确认的身份；退出服务器会清空临时显示限制。客户端与服务器的 Gameplay 应一起升级。

备份和恢复时应一起保留世界数据与玩家数据。两者不是同时写入磁盘；断电或单独回滚部分存档，仍可能使药水消耗与种族保存的时间点不同。

生存获取方式与成长仍待开发；历史检查见[种族系统报告](reports/2026-09-10-race-selection.md)。
