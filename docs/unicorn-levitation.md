# 独角兽能力：自我悬浮

[文档目录](README.md) → 三族能力 → 独角兽

Gameplay 0.3.3 的开发功能，依赖 Appearance 0.3.5 / API 1.5。移动、保护和液面缓冲修订已通过独立检查，并构建了两包联合测试版。2026-09-11 用户同意推送当前版本；多人及第三方模组兼容仍需专项验证。当前暂不限制魔力，成长等级以后再分配。

## 操作

选择独角兽，按住 R 打开轮盘，选中「自我悬浮」，松开后按 V 准备。生存、冒险和创造模式均可使用，旁观模式除外。

- 在地面按住跳跃键约 0.35 秒开始托举；短按仍是普通跳跃。本次跳跃中离地不会跳过长按门槛。
- 持续按住会向上飞，松开立即停止主动托举。松开时保留已有速度，之后受重力影响。
- 已经在空中时重新按住，会先克服下坠再上升。下落越快，制动所需时间与距离越长；没有瞬间定住或清空下坠速度。
- 方向键始终可以控制水平移动，不需要先按 Shift。上升期间的水平速度约等于原版蹲行速度，转向和停止带有惯性。
- 施法时按住 Shift，会用约 0.4 秒收住正常上升速度并保持高度；水平速度提高到约正常走路速度。持续按住跳跃键并松开 Shift 后恢复上升。这里的 Shift 不触发下蹲或镜头下移。
- 下落时即使先按住 Shift，再按跳跃键，也会先减速并向上托举一小段，再缓缓定高，不会直接锁在原高度。
- 液面悬浮使用正常走路的水平速度，不要求按住 Shift。上升、回托、定高、落地缓冲和液面悬浮期间均禁用冲刺；只开启技能而仍在地面时不限制普通冲刺。
- 再按 V 取消准备。创造模式若正在使用原版飞行，按 V 会先退出原版飞行，让悬浮接管；取消准备后恢复原版双击跳跃的操作，不自动重新起飞。飞行权限本身保留。

按键遵循原版绑定。飞行中保留正常碰撞与物品使用。念力出窍期间保留悬浮的开启状态，只暂停本体托举；返回后松开跳跃键再按住即可继续使用，不用重新按 V。出窍仍需在地面发动。

切屏、背包和能力轮盘不会关闭技能，此时暂不读取方向、跳跃和潜行键，自动保护继续生效。单人暂停会保留状态。

受击只打断当前托举，不关闭悬浮开关。角色保留击退和原有速度，随后正常下落；松开跳跃键再按住即可重新施法。落地缓冲、液面悬浮和摔落免伤仍然有效。

骑乘、睡眠、鞘翅、急流、潜入液体、原版飞行和临时切换视角只暂停本体托举。恢复正常状态后，松开跳跃键再按住即可继续；骑乘时保留马的跳跃和 Shift 下马操作。

正常操作不会自动关闭开关。手动关闭、死亡、离线、换维度或失去种族资格会结束当前会话；网络超时与异常移动仍有保护检查。当前不跨登录保存开关状态。

## 自动保护

落地缓冲、液面悬浮和摔落免伤都需要先开启技能。松开跳跃键只停止主动托举；按 V 关闭技能会同时关闭这些保护。后续再分配成长等级。

落地缓冲只在预计会摔伤的下落中启用，根据坠速和脚下距离提前制动。安全的小落差不播放缓冲动作。

技能开启期间直接免疫摔落伤害，不再要求连续低速采样。即使地面出现太晚、缓冲来不及完成，也不会因摔伤中断技能；物理运动仍保留制动过程和碰撞。关闭技能后恢复原版摔伤规则，不清除已积累的下落距离。空中临时开启技能可以救命，但必须在服务端收到开启请求后才生效。

走到水面或岩浆面上时会轻轻托起，脚底与液面保留小段距离。从空中落向液面时，会按当前坠速提前缓冲，逐渐减速后接入液面悬浮；即使落差不足以造成摔伤，也会平缓承接，不会突然锁住高度。离开液面后恢复普通规则。

这不提供游泳、潜水、火焰或岩浆伤害免疫；已经深入液体时也不会从水底直接拉回液面。若贴近液面才开启技能，或液面太晚进入有效探测范围，仍可能来不及刹住而接触液体。

## 魔力与成长

本轮暂停魔力消耗与不足限制，并移除魔力槽，先验收移动和自动保护。旧存档中的魔力数据不删除，当前不用于限制能力；以后再统一三族能力的魔力与成长系统。

## 实现与验证边界

玩法包负责输入、资格、移动和同步。客户端执行共享的运动计算并使用原版碰撞移动，服务端检查会话、输入次序与移动预算。原版碰撞与移动检查保留，只在有效施法期间处理浮空判定。此实现仍需在实际服务器、网络延迟和第三方反作弊环境下验证。

本轮悬浮协议为 v3，测试时客户端和服务器需一起更新。旧开发快照不会与新的 Shift、回托和开关规则混用。

外观包只提供已有飞行姿态、魔法颜色、包身光、角光和声音。API 的飞行活动注册不会设置原版 `allowFlying`、`flying`、无敌或穿墙标记；无翼小马沿用站立悬浮姿态。屏幕边缘光罩只在第一人称显示。

验收重点：普通方向移动不退出、Shift 定高加速且不下蹲、松开跳跃后下落、不同高度的缓冲与伤害、落向水面及岩浆面的连续减速、液面跨格移动，以及创造模式与原版飞行的切换。另需检查顶到天花板、转向惯性和多人视角下的角光与飞行姿态。液面悬浮不提供岩浆免疫，首次验收建议使用可恢复的测试世界。

### 2026-09-11：空中续按与视角纠正

试玩发现，上升时反复松开、重按跳跃键，可能让视角归零并关闭技能。重按等待确认期间，客户端仍按重力下落，而服务端已按上升检查位移，容易触发纠正；纠正又错误地把目标角度传成了零。短时间内反复纠正会被判定为持续异常移动。

修订后，同次已确认的空中施法可以立即续按；落地、关闭或会话失效后仍需重新确认。松开时同步清除旧移动预算与充能状态。位置纠正保留当前角度，正常释放时的惯性、地面长按门槛和异常移动检查均保留。

专项 Java 检查通过：包含 96 组各 400 刻的松按与延迟确认轨迹、落地后重新充能，以及执行原版传送方法的视角回归。旧会话代码会在新增续按测试中失败。本轮检查未重新打包或进行实机验收；此前导出的 JAR 不含这项修复。
