# 独角兽能力：念力出窍

[文档目录](README.md) → 三族能力 → 独角兽

选择[独角兽种族](races.md)后，可将视角附着于魔法光团，远程移动、携物和交互。当前开放 9 格独立物品栏、128 格控制范围、精神回声和携物回航，成长等级以后划分。依赖版本见[安装说明](../README.md#安装)。

已派出的[御物](telekinesis.md)工具可在出窍期间继续工作；出窍期间不能新派工具。照明能力仍在[规划](unicorn-ability-plan.md)中。

此前版本的检查范围与结果见[物品朝向与拾取修复](reports/2026-09-10-remote-pickup-pose.md)和[试玩反馈修复](reports/2026-09-11-remote-playtest-fixes.md)。

## 入口与操作

- 客户端与服务器需安装匹配版本。选择独角兽后启用能力；管理员可用 `/magicaland remote_tool revoke <players>` 撤回，`grant` 恢复。其他种族即使持有旧授权标签也不能使用，外观选择不授予能力。
- 按住 R 选中「念力出窍」，松开后按 V 发动或返回；两键可改绑。出窍中可切换轮盘选择，右键出窍图标直接返回。
- 模组列表 → Magical Land: Gameplay → 设置 →「能力视角」可选自动背面第三人称（默认）或沿用发动前本体视角。设置点击即保存，发动时读取一次，仍可按 F5 切换；结束远控后恢复发动前的视角。
- WASD 按投影视角飞行，跳跃上升，潜行下降。鼠标只改变投影观察方向；本体仍站在原处，受正常重力、伤害和世界规则影响。
- Esc 打开菜单或切换窗口时保留会话，暂停移动与交互输入。出窍期间不能打开本体背包；视角回到本体后恢复。
- 自我悬浮已开启时也可在地面发动出窍。远控期间暂停本体托举，保留悬浮开关；返回后松开跳跃键再按住即可继续托举。已派出的御物工具继续工作，正常卸货或归还不会打断远控。
- 出窍物品栏采用原版样式，显示数量、耐久和选中槽。9 槽均已开放，遵守物品自身堆叠上限：普通物品最多 64 个，剑、镐等不可堆叠工具每槽 1 件。
- 滚轮和数字键选择独立的出窍槽，不修改本体快捷栏选中槽。客户端先呈现选择，服务器按会话和输入序号校正。
- Q 从当前出窍槽丢出 1 个，Ctrl+Q 丢整栈，按键沿用原版绑定。物品从光团前抛，2 秒后可再拾取。本体失去能力资格时不执行；生成受阻或失败时保留物品。本体至光团遮挡不影响丢弃，本体背包也不参与操作。
- 管理员可用 `/magicaland remote_tool slots <players> <count>` 临时测试 1–9 槽。命令先结束会话，有货槽不能裁掉，重载存档后恢复 9 槽；成长、经验和魔力尚未接入。

## 真实物品归属

- 发动时，从本体当前主手槽按物品自身堆叠上限真实转移到一个可用出窍槽。源背包扣除实际转移量；工具、附魔、名称、耐久和 NBT 保留。物品剩余量仍归本体。
- 出窍携带的物品存放在服务端管理的独立物品栏中。拾取、使用、耐久消耗和返还都以这份记录为准；投影实体只同步显示副本。回航时若选中槽为空，会展示其他槽中的货物。
- 当前选中工具坏掉后槽变空，控制继续。空槽可以拾取新物品；拾物先合并兼容堆叠，再填空槽，不混合不同物品或不同 NBT。
- 拾物继续尊重拾取延迟、拾取归属 UUID 和投影到掉落物中心的碰撞射线；投掷者身份不会限制普通掉落物的拾取。只从世界物品中扣除实际收入量，剩余留在原处。本体至光团完全遮挡时仍可拾物，但不能隔着光团附近的实际障碍物收取掉落物。
- 正常回航抵达本体后，原带出物品优先尝试原槽，再补兼容堆叠和空槽，不覆盖本体后来放入的物品。装不下的余量落在本体脚边；掉落生成失败或本次处理未完的物品留在持久库存，稍后重试。附魔、名称、耐久和 NBT 保留，重复关闭不会重复返还。
- 死亡时遵守 `keepInventory`；关闭保留物品时，远程库存掉落在本体处，消失诅咒物品按原版规则消失。断线、换维度、服务器停止或实体异常卸载时停止回航，未结算的货物仍保存在玩家 UUID 对应的持久库存，待正常上线或状态恢复后处理。

## 存档迁移与崩溃限制

继续使用主世界 `PersistentState` 的 `magicaland_remote_cargo` 存档及玩家 UUID 所有权，保留 `Players`、`Owner` 和 `Items`。Version 2 新增物品槽号、解锁槽数及选中槽；空的已扩容库存也保存解锁设置。

旧单槽 `Items` 原位迁入第一个槽，读取后开放 9 槽，保存为 Version 2。新版按槽号恢复，保留中间空槽；超限或无法正常放入的旧物品进入持久恢复余量，随返还或死亡处理。

正常运行时，物品转移和返还在同一服务端线程完成，保持转移前后的数量一致；重复关闭会话也不会重复返还物品。玩家原背包和世界 `PersistentState` 分开保存，无法保证两份存档同时写入磁盘。异常崩溃、断电或单独回滚一份存档时，最后保存时点不同仍可能造成物品重复或丢失。

升级前应保留整个世界及玩家数据的一致备份；新多槽存档不支持直接降回旧单槽版本。

## 光团遮挡与精神回声

遮挡比例从本体眼睛到光团采样，与出窍画面占比和本体视角锥无关。手动控制时本体通过公开外观接口注视光团，回航时解除注视。

- 以朝向本体的稳定采样圆盘近似光团控制区域，共 25 条视线。`RemoteVisibility.OCCLUSION_SAMPLE_RADIUS = .75`，即直径约 1.5 格，给予墙角和掩体边缘较宽的过渡。
- 采样范围与光团美术、碰撞箱、128 格控制范围和 3 格交互距离分别计算。
- 虚拟采样点碰到附近地板、墙、半砖或楼梯时，先截在球心一侧的表面前，再检查本体到该点的视线。贴近无遮挡平地不会因采样点钻入地板而误黑；实际隔墙、隔地板或顶棚仍会遮挡。
- 按方块实际轮廓形状检查遮挡。普通玻璃、染色玻璃及相应玻璃板透过视线；遮光玻璃仍遮挡。视线可穿过没有碰撞体积的草、花、甘蔗等装饰植物，实体墙和有碰撞的植物仍按原规则判断。光学规则与飞行碰撞分开：能透过玻璃维持连接，也仍不能飞过玻璃。采样遇到未加载区块按遮挡处理。
- 部分遮挡时仍可控制和交互，客户端按服务器比例平滑收暗。操作目标必须通过投影出发的射线、距离和权限检查。
- 全遮挡时仍可移动、观察、交互和拾物；继续深入也不自动退出。移动仍受 128 格范围、碰撞及已加载区块边界限制。
- 正常画面在全遮挡时压黑，精神回声每 3 秒从光团向外扫过 8 格，波传播约 0.7 秒。扫到的轮廓在随后约 3 秒中逐渐变淡，接近消失时由下一轮重新扫亮；换轮时保留尚未淡完的旧波，两轮重合也不会叠加变亮。回声只显示近处可见表面和实体的轮廓，不恢复正常纹理。
- 回声从当前镜头已渲染的局部深度提取轮廓，第三人称沿用跟随镜头视野；不扫描墙后矿脉或生物，也不按矿种、敌友着色。交互仍由光团出发的服务端射线验证。

检测到 Iris、Oculus 或 OptiFabric 时暂停回声绘制；深度缓冲或回声处理不兼容时也会停止该效果并提示仍可返回。本体至光团的遮挡规则和正常退出继续生效。其他第三方渲染组合与多人负载下的表现尚未全面确认。

## 携物回航

退出时先通过短暂淡出、淡入恢复本体视角。整个出窍物品栏都为空时，光团直接消失；有货时保留光团，等待 6 tick（服务器正常运行时约 0.3 秒）后开始回航。

光团追随本体的当前位置，有通路时直接靠近，否则利用来路记录并逐步搜索绕行路线。移动遵守实体大小、方块碰撞、已加载区块和世界边界。门被关上或道路被堵住时，会停下并重试，提示“回航受阻”；不会因等得久而穿墙或把货物直接送进背包。

视角回来后，本体可以移动、转头、切物品或打开背包。回航光团不再攻击、挖掘、操作或拾物；到货前不能再次发动出窍。角光持续到光团消失，携货显示保留原有惯性和物品朝向，不重播掏出动作。

抵达本体附近且最后一段路径可通行后，按[真实物品归属](#真实物品归属)中的顺序交付。死亡、断线、换维度及异常卸载走持久库存恢复流程。实现和检查范围见[回航记录](reports/2026-09-11-remote-return.md)。

## 交互与动作反馈

远控和携物回航期间，通过外观 API 的施法活动注册维持角部光效，空手出窍也生效。光团消失后按正常持物状态决定是否发光；普通注视和捏脸预览不触发这项施法状态。

第三人称工具朝观察镜头的侧边偏移 0.30 格，左手镜像。此偏移只作用于显示，实体位置、碰撞箱和服务器射线保持原位。HUD 将现有交互射线的目标投影到实际屏幕位置，冷却条随准星移动；目标位于镜头背后或画面外时隐藏。完整功能下部分和全遮挡均保留准星，以支持精神回声中的手动操作；返程或隐藏 HUD 时停显。第一人称沿用中心准星。

第三人称空手投影显示发光内核与收尖焰尾，调用 Magical Land 的公共 `renderFlame` 接口，移动时尾部向速度反方向延展。携物回航时，较小的光焰与物品同时显示。第一人称保留原持物与边缘光流提示；美术形状不参与碰撞和遮挡采样。

第三人称惯性锚点由实际世界渲染矩阵还原。工具静止时斜向上约 45°，小幅跟随俯仰；平面物品正立朝向镜头，立体物品保持竖直。显示抵消模型自带的持握旋转，保留运动惯性；远端角度沿最短方向插值。第一人称和本体收放使用各自原有路径。

服务端分别维护会话生命周期、远程库存、挖掘进度和动作时间线。动作类型包含空挥、命中、持续采矿、工具使用、破坏完成和工具断裂，携带动作序号与世界 tick 起点。第一人称和其他观察者看到的世界工具使用同一份权威动作；持续挖掘循环，松键、切目标、选槽或右键会结束当前挖掘状态。本体至光团全遮挡时仍可挖掘，操作目标须通过光团出发的交互检查。

- 工具和武器沿用已有攻击规则，挖掘工具可持续挖掘。普通非工具物品也可左键攻击，伤害按原版空手的一半计算；选中空槽时不能攻击。空挥、命中、挖掘声音及碎屑、破坏和断裂反馈由动作结果驱动。
- 右键支持门、活板门、栅栏门、拉杆、按钮，以及原版挖掘工具的锄地、铲路、斧头去皮等行为。铁门等方块保留自身规则。
- 选中出窍物品栏里的食物，可以吸引喜欢该食物的动物靠近光团，普通玩家手持食物的吸引优先。右键可用选中食物喂养对应动物，沿用原版喂食、繁殖和消耗规则；回航期间不吸引、喂食或执行其他交互。
- 权限检查、Fabric 攻击/使用事件、方块破坏流程和掉落继续使用真实玩家身份。服务端决定目标、伤害、进度和库存，客户端不能直接提交被攻击者或完成挖掘。
- 交互作用域向原版流程提供远程选中工具、挖掘速度、收获判断、耐久写回、附魔及独立攻击冷却。攻击属性在副本上去除本体主手修饰，再应用远程主手修饰，保留玩家基础属性和其他效果，不改真实装备属性容器。
- 不临时移动本体位置、不临时替换真实主手、不创建假玩家。攻击音源、横扫、基础及附魔击退方向、盾牌方向判断使用投影空间；伤害和权限归属仍是玩家。横扫副目标也执行权限和遮挡检查。
- 门/工具使用等原版广播排除了操作者，或声音只按本体位置分发时，在当前交互作用域补发遗漏的反馈；已经收到正常广播的声音不重复发送。
- 直接读取玩家内部背包或位置的第三方领地／物品模组，其兼容性尚未确认。

尚未支持容器界面、普通方块放置、弓弩、三叉戟投掷，以及玩家自身进食、饮药等持续使用行为；喂养动物已单独支持。

## 范围、网络与模块边界

能力视角保存在 `config/magicaland-gameplay/client.json`，通过 Mod Menu 的玩法设置修改，也可关闭游戏后编辑文件。首次缺少该文件时，会在外观预设重存前读取旧选择完成迁移，此后独立保存。主模组 F9 菜单不包含此选项，专用服务端不生成客户端设置。

- 本体眼睛周围 128 格硬范围，移动上限每 tick 0.3 格，平滑加减速；交互射线从投影眼睛延伸 3 格。碰撞仍由服务端处理，不进入未加载区块、世界边界外或高度边界外，不因扩展控制范围强制加载区块。服务器视距、实体跟踪和玩家实际接收的区块可能进一步限制可达范围。
- 一名玩家最多一个手动控制或回航中的光团，全服两者合计最多 64 个。控制包含请求标识、服务器会话标识、递增输入序号、方向、按键和独立选中槽。服务端校验消息长度、数值、归属及槽位范围。
- 手动控制连续 5 tick 没有新输入后清空操作，40 tick 后结束控制并按携货情况处理。自动回航不依赖客户端持续发包；旧输入、重复停止和本体操作包不会重新操控或终止回航。
- 新协议使用 `remote_control_v2` / `remote_state_v2` 两个通道，防止旧客户端按旧单槽物品格式误读。两端 Gameplay 需一起升级，旧控制通道不再注册；实体 ID、管理员授权标签和旧库存存档名保留。
- Gameplay 负责能力规则、库存、网络、客户端控制及 HUD，Magical Land 负责通用视觉。Gameplay 通过公开 API 查询魔法色、注册注视覆盖与施法活动、绘制光团和持物，不访问主模组内部缓存、骨骼或合成状态。
