# 念力出窍

当前开发版本为 Gameplay 0.2.2，客户端使用外观 0.3.3 / 公共 API 1.3。包含能力视角偏好、第三人称工具侧移与瞄准点、空手光焰显示。2026-09-10 已构建包含独立设置页的两包测试版，用户完成本次实机验收并同意合入；多人及第三方模组兼容仍需专项验证。

0.2.1 测试后追加了物品朝向和重新拾取修复，已重新构建，并通过用户本轮体验验收，见[追加修复记录](reports/2026-09-10-remote-pickup-pose.md)。这不代替多人、特殊资源包和第三方模组的专项兼容验收。

## 入口与操作

- 两端需要匹配的 Gameplay 0.2.2 和兼容外观包。管理员用 `/magicaland remote_tool grant @s` 授予测试能力，`revoke` 撤回；外观、角型或魔法色不授予服务端权限。
- 按住 R 打开能力轮盘，选择「念力出窍」，松开只选择。V 发动或返回，两键可改绑。
- 模组列表 → Magicaland Gameplay → 设置 →「能力视角」可选自动背面第三人称（默认）或沿用发动前本体视角。发动时读取一次，仍可按 F5 切换；结束远控后恢复发动前的视角。
- WASD 按投影视角飞行，跳跃上升，潜行下降。鼠标只改变投影观察方向；本体仍站在原处，受正常重力、伤害和世界规则影响。
- 出窍 HUD 使用原版快捷栏的底框、选中框、物品数量和耐久显示。初始开放 1 槽，每栈最多 8 个，并尊重物品自身上限；剑、镐等不可堆叠工具只占 1 槽、数量 1。
- 滚轮和数字键选择独立的出窍槽，不修改本体快捷栏选中槽。客户端先呈现选择，服务器按会话和输入序号校正。
- Q 丢出当前出窍槽中的 1 个物品，Ctrl+Q 丢出整栈，沿用原版丢弃键绑定。掉落物从投影处轻轻向前抛出，遵守方块碰撞，2 秒后可以再次拾取；不会从本体背包丢物品。完全遮挡或本体不再满足能力条件时不执行丢弃，生成位置受阻或生成失败时保留原物品。
- 管理员可用 `/magicaland remote_tool slots <players> <count>` 把测试槽数设为 1–9。该命令先结束现有会话；有物品的槽不会被裁掉。这是多槽接口的验收入口，不包含成长、经验、魔法值或升级解锁玩法。

## 真实物品归属

- 发动时，从本体当前主手槽真实转移最多 8 个物品到一个可用出窍槽。源背包扣除实际转移量；工具、附魔、名称、耐久和 NBT 保留。物品剩余量仍归本体。
- 远程库存是唯一权威存储，投影实体仅同步当前选中物品的展示副本。所有拾取、使用、耐久损耗和返还都操作远程库存，没有「本体真工具加投影借用栈」分支。
- 当前选中工具坏掉后槽变空，控制继续。空槽可以拾取新物品；已有工具占掉唯一槽时不会另外多出一个拾物槽。开放多槽后，拾物先合并兼容堆叠，再填空槽，不混合不同物品或不同 NBT。
- 拾物继续尊重拾取延迟、拾取归属 UUID 和投影到掉落物中心的碰撞射线；投掷者身份不会限制普通掉落物的拾取。只从世界物品中扣除实际收入量，剩余留在原处。完全遮挡时停止拾物。
- 正常返回先尝试本体原槽，再补兼容堆叠和空槽；不会覆盖本体后来出现的物品。背包满时余量留在出窍库存，并提示下次腾出空间后取回。重复关闭不会重复返还。
- 死亡时遵守 `keepInventory`；关闭保留物品时，远程库存掉落在本体处，消失诅咒物品按原版规则消失。关闭会话和处理死亡掉落相互独立，取出掉落列表只执行一次。正常断线、服务器停止和换维度会清理会话并结算库存。

## 存档迁移与崩溃限制

继续使用主世界 `PersistentState` 的 `magicaland_remote_cargo` 存档及玩家 UUID 所有权，保留 `Players`、`Owner` 和 `Items`。Version 2 新增物品槽号、解锁槽数及选中槽；空的已扩容库存也保存解锁设置。

旧单槽 `Items` 没有槽号，读取时原位迁入默认单槽；不需要先复制到第二份玩家存档。新版稀疏槽位按槽号恢复，空槽不会被压缩。超限或无法放入正常槽的旧数据进入持久恢复余量，之后随返还或死亡处理，不静默截断丢弃。

玩家原背包和世界 `PersistentState` 仍是两份独立存档。同一服务端线程中的转移、返还和幂等关闭保证正常运行路径的数量守恒，但不构成磁盘原子事务。异常崩溃、断电或单独回滚一份存档时，最后保存时点不同仍可能引起重复或丢失；本实现不宣称已解决该边界。升级前应保留整个世界及玩家数据的一致备份；新多槽存档不支持直接降回旧单槽版本。

## 光团遮挡与回归

遮挡指本体眼睛看向光团的遮挡比例，不是出窍镜头里黑色画面的比例，也不由本体视角锥决定。本体持续注视投影，头眼动作仍由现有公开外观接口控制。

- 以朝向本体的稳定采样圆盘近似光团控制区域，共 25 条视线。`RemoteVisibility.OCCLUSION_SAMPLE_RADIUS = .75`，即直径约 1.5 格，给予墙角和掩体边缘较宽的过渡。
- 采样范围独立于美术核心、泛光半径、持物模型和实体实际碰撞箱。放大这个参数不会让光团模型或碰撞变大，也不改变 16 格控制范围及 3 格交互距离。
- 虚拟采样点碰到附近地板、墙、半砖或楼梯时，先截在球心一侧的表面前，再检查本体到该点的视线。贴近无遮挡平地不会因采样点钻入地板而误黑；实际隔墙、隔地板或顶棚仍会遮挡。
- 按方块实际轮廓形状检查遮挡。普通玻璃、染色玻璃及相应玻璃板透过视线；遮光玻璃仍遮挡。光学规则与飞行碰撞分开：能透过玻璃维持连接，也仍不能飞过玻璃。采样遇到未加载区块按遮挡处理。
- 部分遮挡时仍可控制和交互，客户端按服务器比例平滑收暗。操作目标仍必须通过投影出发的射线、距离和权限检查。
- 全部采样遮挡后，立刻停止交互、清除挖掘进度和停止拾物，保留移动与观察。停留、纯转头、残余滑行不触发定时退出。
- 全遮挡时记录进入位置和深入方向；此后沿该方向的净深入位移达到 0.75 格，且本 tick 的主动输入与实际移动都在继续深入时，才自动回归。横向绕行不累加这个深度，后退会降低净深入量，重新出现可见采样会恢复并重新建立边界。
- 若门或活塞在光团静止时关闭，零入口位移使用本体到光团的方向作为备用轴，仍能区分继续远离、横移和后退。
- 回归使用短淡出、视角还体及淡入，不包含自动寻路飞返。身体受伤、死亡、异常移动、权限撤回、维度变化、窗口失焦和输入持续失联等安全退出独立于遮挡过渡。

## 交互与动作反馈

远控期间通过外观 API 的可撤回施法活动注册维持角部光效，空手投影也生效。本体恢复后按正常持物状态熄灭或继续发光；未把普通注视目标当作施法状态，捏脸预览也不读取这个活动。

第三人称工具朝观察镜头的侧边偏移 0.30 格，左手镜像。此偏移只作用于显示，实体位置、碰撞箱和服务器射线保持原位。HUD 将现有交互射线的目标投影到实际屏幕位置，冷却条随准星移动；目标位于镜头背后或画面外时隐藏。全遮挡、返程或隐藏 HUD 时停显，部分黑边按目标所在位置淡化准星。第一人称沿用中心准星。

第三人称空手投影显示发光内核与收尖焰尾，调用外观包公共 `renderFlame` 接口，移动时尾部向速度反方向延展。第一人称保留原持物与边缘光流提示；美术形状不参与碰撞和遮挡采样。

第三人称惯性以实际世界渲染矩阵还原锚点，包含镜头旋转和原版视角效果，不再从相机方向四元数猜测坐标。工具静止时约斜向上 45°，俯仰只小幅影响姿态；普通平面物品正立并将像素画面朝向观察镜头，仍保留运动中的惯性。方块等立体物品保持立体且竖直。显示朝向会抵消当前模型自带的持握旋转，不移动惯性锚点；远端观察者的角度更新沿短方向插值。第一人称和本体的原收放路径不改。

服务端分别维护会话生命周期、远程库存、挖掘进度和动作时间线。动作类型包含空挥、命中、持续采矿、工具使用、破坏完成和工具断裂，携带动作序号与世界 tick 起点。第一人称和其他观察者看到的世界工具使用同一份权威动作；持续挖掘循环，松键、切目标、选槽、全遮挡或右键会结束当前挖掘状态。

- 剑及挖掘工具可近战；挖掘工具可持续挖掘。空挥、命中、挖掘声音及碎屑、破坏和断裂反馈由动作结果驱动。
- 右键支持门、活板门、栅栏门、拉杆、按钮，以及原版挖掘工具的锄地、铲路、斧头去皮等行为。铁门等方块保留自身规则。
- 权限检查、Fabric 攻击/使用事件、方块破坏流程和掉落继续使用真实玩家身份。服务端决定目标、伤害、进度和库存，客户端不能直接提交被攻击者或完成挖掘。
- 交互作用域向原版流程提供远程选中工具、挖掘速度、收获判断、耐久写回、附魔及独立攻击冷却。攻击属性在副本上去除本体主手修饰，再应用远程主手修饰，保留玩家基础属性和其他效果，不改真实装备属性容器。
- 不临时移动本体位置、不临时替换真实主手、不创建假玩家。攻击音源、横扫、基础及附魔击退方向、盾牌方向判断使用投影空间；伤害和权限归属仍是玩家。横扫副目标也执行权限和遮挡检查。
- 门/工具使用等原版广播排除了操作者，或声音只按本体位置分发时，在当前交互作用域补发遗漏的反馈；已经收到正常广播的声音不重复发送。
- 第三方领地或物品模组若绕过标准查询而直接读玩家内部背包/位置，仍需针对性兼容验收，不能视为已覆盖全部模组。

本轮不开放容器界面、普通方块放置、弓弩、三叉戟投掷、食物药水及其他持续使用物品。可携带某物品不代表已经实现它的全部使用能力。

## 范围、网络与模块边界

能力视角由玩法客户端独立保存于 `config/magicaland-gameplay/client.json`。首次缺少该文件时，只读迁移旧外观配置中的选择；迁移在客户端的通用初始化阶段完成，早于外观预设加载时重新保存配置。此后不读取或修改外观设置。模组列表入口由可选的 Mod Menu 提供，没有 Mod Menu 时仍可通过此配置文件调整。外观 F9 菜单不再包含玩法视角按钮，专用服务端不加载或生成客户端设置。

- 保留本体眼睛周围 16 格硬范围，移动上限每 tick 0.3 格，平滑加减速；交互射线从投影眼睛延伸 3 格。碰撞仍由服务端处理，不进入未加载区块、世界边界外或高度边界外。
- 一名玩家最多一个会话，全服同时最多 64 个。控制包含请求标识、服务器会话标识、递增输入序号、方向、按键和独立选中槽。服务端校验消息长度、数值、归属及槽位范围。
- 连续 5 tick 没有新输入后清空移动和操作输入，40 tick 后关闭。旧输入、旧会话停止消息和过期状态不能操控新会话。
- 新协议使用 `remote_control_v2` / `remote_state_v2` 两个通道，防止旧客户端按旧单槽物品格式误读。两端 Gameplay 需一起升级，旧控制通道不再注册；实体 ID、管理员授权标签和旧库存存档名保留。
- Gameplay 拥有能力规则、库存、网络、客户端控制及 HUD；外观包拥有通用视觉实现。只调用公开 API 查询魔法色、注册可撤回的注视覆盖与施法活动、渲染光团/持物，不访问外观内部缓存、骨骼或合成状态。

## 验证

最初重构（0.2.0）的检查范围和证据见[重构报告](reports/2026-09-10-remote-rebuild.md)；本轮 0.2.1 的修复与检查见[验收反馈修复](reports/2026-09-10-remote-followup.md)。报告分别记录独立检查、构建和用户验收。

回归入口位于 `tests/remote`：

- `RemoteToolMathTest`：方向、归一化速度及本体头眼跟随。
- `RemoteSessionRulesTest`：部分/全遮挡状态、长时间停留、横移、斜向深入、后退、惯性、纯转头、静止环境遮挡备用轴、输入有序性及幂等关闭。
- `RemoteProtocolTest`：v2 各类消息、长度、尾部数据、非法数值、会话和槽位边界及动作枚举。
- `RemoteCargoInventoryTest`：上限与 NBT 兼容、真实迁入、工具耐久、坏工具空槽、多槽及稀疏保存、旧存档迁移、恢复余量、满包和重复结算数量守恒。
- `RemotePickupTest`：真实掉落物拾取归属与投掷者区分、延迟、丢出后收回、容量与 NBT、平地/半砖和实际障碍物。
- `RemoteVisibilityTest`：固定大采样半径、竖直基底、墙角渐进、贴地/半砖/楼梯采样、真实隔墙与顶棚、玻璃光学与碰撞分离、遮光玻璃。
- `RemoteAttributesTest`：物品攻击属性投影、保留其他属性效果及不修改本体属性实例。
- `RemotePresentationTest`：客户端会话、输入/状态次序、选槽及视觉纯规则。
- `RemoteItemPoseTest`：工具斜向上、普通物品正面朝镜头且不镜像、左右手与模型显示旋转、立体物品竖直、挥动及角度跨界连续性。
- `RemoteAimMathTest`：第三人称目标投影、画面边界及遮挡时准星透明度。
- `RemoteStructureTest.mjs`：协议、权限、真实库存、公开 API 和作用域源码边界。

`tests/config/run-tests.ps1` 使用真实 Gson、Mod Menu 入口和实际设置页处理器，覆盖独立保存、旧选择提前迁移、外观随后重存、专用服务端不生成客户端设置、保存失败及重试。本次 380 项检查通过；最新全源码 Java 17 类型检查、296 项架构与 110 项远控边界检查通过，玩法编译仅依赖外观公共 API。

独立编译、纯规则回归及真实 Fabric 类加载器的 Mixin 装配检查都不等于正式 Loom 发布构建，也不等于实际世界或多人交互验收。仍需在游戏中检查墙角/上下掩体、网络延迟、第一/第三人称动作与音源、附魔工具和盾牌、权限回调、满包、死亡、断线及返回恢复。
