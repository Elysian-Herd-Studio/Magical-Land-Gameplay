# 独角兽能力规划

[文档目录](README.md) → 三族能力 → 独角兽

2026-09-11 确定开发顺序：先开放完整功能，再划分成长等级、解锁顺序和魔力消耗。陆马感知与自我悬浮同样遵循此原则。

## 已实现能力

- [念力出窍](remote-presence.md)：附着光团远程移动和交互，遮挡时通过精神回声辨路，结束后携物回航。
- [自我悬浮](unicorn-levitation.md)：托举、惯性移动、落地缓冲与液面悬浮。
- [御物](telekinesis.md)：工具自动护卫或执行指定任务，支持连采和携货返回。

具体操作、数值和安全边界由各功能文档维护。精神回声侧重近处辨路，[陆马感知](earth-sense.md)依赖地面传播并区分震动类型。

## 待开发：独角照明与悬浮魔法灯

照明包含独角持续照明和悬浮魔法灯，沿用已有魔法色、角光与光团美术。环境照明仅作用于客户端画面，服务器光照、刷怪判断和方块状态保持原有规则。

采用自有渲染，不增加照明依赖；渲染方案、性能预算和着色器兼容方式尚未确定。照明使用独立开关，可与自我悬浮或念力出窍共存。

魔法灯采用固定选点：瞄准有效位置时显示小标记，释放后光团飞过去并停驻；定点星环为标记方案。回收沿用携物回航的绕障逻辑。客户端预览目标，服务器检查距离、视线、权限和目标状态。

同时保留 2–3 盏是数量提案，尚未定案；亮度、照明范围和回收操作也需随功能设计确定。

## 待开发：魔力与成长

- 御物指令与附着操控共用魔力和控制负载预算。
- 自我悬浮有较低的维持消耗；距离、工具动作、多物品负载及进阶隔墙连接分别增加消耗。
- 低魔力时提前提示；耗尽时停止任务并退出附着，工具与携带物通过回航或持久库存归还。
- 成长分为感知、精控和负载：分别拓展距离与连接稳定性、操作和任务能力、携带量与工具数量。
- 隔墙连接的厚度与稳定性可成为成长方向，物品仍受碰撞约束；精神回声只提供局部轮廓。
- 多物品阶段由玩家操控一个镜头，其余工具跟随或执行任务。各工具独立工作，数量增加不直接倍增单块挖掘速度。
- 落地保护与液面悬浮的解锁等级、消耗和数值平衡，在完整能力制作后统一划分。

## 操作与反馈原则

持续能力各自保存开关，切换轮盘选择保留正在运行的能力。提示以轮盘短名称、开启亮点、漂浮物和世界标记为主；用物品栏中的魔法边框表示已派出的工具，以第一人称边缘光和少量星点表示悬浮准备状态。

下一步先制作照明，再统一成长、解锁、消耗和数值平衡。最初的分阶段设计见[2026-09-09 归档](archive/2026-09-09-tribe-stages.md)。
