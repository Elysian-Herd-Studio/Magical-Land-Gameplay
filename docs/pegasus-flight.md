# 天马飞行

天马可在生存与创造模式使用普通飞行、滑翔和自由特技。已制作的能力完整开放，成长等级稍后划分。

## 操作

| 状态 | 操作 |
| --- | --- |
| 起飞／结束飞行 | 双击空格 |
| 普通飞行 | WASD 平移，空格上升，Shift 下降；松开后逐渐悬停 |
| 普通飞行／滑翔 | Ctrl 切换 |
| 滑翔 | 鼠标控制方向，W 拍翼加力，S 减速；俯冲增速，抬头换取高度 |
| 简化操控／自由特技 | 在“天马飞行”设置中选择，也可用 Tab 切换并保存 |
| 自由特技 | 允许完整俯仰回环，A／D 横滚 |

Ctrl 和 Tab 只在天马飞行期间接管，地面、其他种族与界面内保留原有用途。第三人称正面仍按原版方式观察角色，操作方向不随镜头反转。打开界面或暂时切出窗口会停止读取方向输入，不主动切换模式。

每次进入滑翔都读取保存的操控模式。自由特技允许倒飞、回环和横滚；速度越快，单靠鼠标左右转向越慢，大幅转弯需要先用 A／D 倾斜身体，再拉升。简化操控自动倾斜身体完成转弯，各速度下的姿态转向响应一致，抬头爬升、低头俯冲。普通悬停时头部可以独立观察，身体平滑跟随；松开移动键后仍会滑行一小段。滑翔的身体朝向与移动方向分别计算，急转弯会保留惯性。

默认起飞时切到第三人称背面，落地恢复起飞前的视角。可以在玩法包的“天马飞行”设置中改为保持当前视角，与念力出窍的视角设置互不影响。飞行期间手动切换视角后，落地不再强制切回。

体力容量为 1000，快捷栏上方显示余量。按住 W 后推力约用一秒展开，速度继续增长；持续加力时俯冲比平飞稍快。松开后推力渐弱，耗尽后需松开 W、恢复体力再按；普通飞行和惯性滑翔仍可继续。

## 落地与碰撞

- 非滑翔坠落接近地面时拍翼减速，落地不重复结算旧的坠落距离。滑翔期间不触发这项保护。
- 滑翔正面撞上地形且速度足够时产生冲击波和范围伤害，随后团身回弹、展开并恢复悬停。擦碰不触发砸击；地形不被破坏。
- 撞击越快，伤害、冲击范围和震动越强；进入危险速度后自身也会受伤。
- 地面保护在滑翔即将撞地时提前拉起，贴近地面时减小下坠速度。砸地尚未解锁、冷却中或撞击速度／角度不足时提供辅助；满足砸地条件时正常撞击。拉起需要头顶空间，辅助沿途只检查已加载的碰撞体。
- 关闭地面保护后，低速滑翔实际接触地面会结束飞行，恢复地面操作；滑翔落地仍按实际坠落情况处理伤害。也可以先切回普通飞行再落地。
- 水中双击空格可以进入天马飞行。浅角滑翔接近水面时会轻微拉起；按实际下降轨迹判断，43°以内完整辅助，43°–55°逐渐减弱，55°以上允许主动扎入水中并结束滑翔。辅助不作用于岩浆，也不会隔着岸边方块托起角色。
- 冲撞生物按双方相对接近速度计算伤害与击飞。近似同速、同向并飞不造成伤害；有效命中后减速，但继续飞行。
- 伤害遵守服务器 PvP 规则，并排除同队成员和自己的宠物。同一次接触不会连续重复结算。
- 不飞入未加载区块或越过世界边界；死亡、换维度、传送、改族及不适用的活动状态会清理飞行状态。

起飞时登记 48 格内最近的最多 64 只普通怪物，暂时避免它们因飞行拉远距离而消失。最长保留 60 秒；玩家飞离起飞点水平 64 格、落地或结束飞行后解除，模式切换不续期，也不追加目标。怪物仍可被击杀，和平难度照常清除；不写永久持久化标记，不额外加载区块。

飞行风声、白色翼尖拖尾和附近撞击震动用于反馈速度与冲击。风声音量、飞行及撞击震动可在玩法包的“天马飞行”设置中减弱或关闭。

水面保护和地面保护默认开启，可在“天马飞行”设置中分别关闭，选择会自动保存。

## 实现边界

飞行运动、体力、碰撞与伤害由服务端结算，客户端预测并校正位置。区块沿飞行路线正常加载，移动受已加载范围和世界边界限制。Magical Land 通过公共 API 1.6 接收飞行姿态，负责模型转向、拍翼和团身。依赖版本见[安装说明](../README.md#安装)，第三方渲染与反作弊的兼容性尚未确认。

彩虹音爆、音爆前即死速度段、突破后的撞地免伤均未启用，留待确定触发条件后制作。气流托举、尾流领航和天气互动同样属于后续方向。
