# 天马飞行

2026-09-13 开发测试版，等待实机验收。玩法身份需要是天马；生存与创造均可测试。当前先开放已制作的完整能力，成长等级稍后划分。

## 操作

| 状态 | 操作 |
| --- | --- |
| 起飞／结束飞行 | 双击空格 |
| 普通飞行 | WASD 平移，空格上升，Shift 下降；松开后逐渐悬停 |
| 普通飞行／滑翔 | Ctrl 切换 |
| 滑翔 | 鼠标控制方向，W 拍翼加力，S 减速；俯冲增速，抬头换取高度 |
| 简化操控／自由特技 | 在“天马飞行”设置中选择，也可用 Tab 切换并保存 |
| 自由特技 | 允许完整俯仰回环，A／D 横滚 |

Ctrl 和 Tab 只在天马飞行期间接管，地面、其他种族与界面内保留原有用途。第三人称正面仍按原版方式观察角色，操作方向不随镜头反转。打开界面或暂时切出窗口会停止读取方向输入，不主动切换模式。

每次进入滑翔都读取保存的操控模式。简化操控会保持姿态平稳；自由特技允许倒飞、回环和横滚。普通悬停时头部可以独立观察，身体平滑跟随转向。滑翔的身体朝向与移动方向分别计算，急转弯会保留惯性。

默认起飞时切到第三人称背面，落地恢复起飞前的视角。可以在玩法包的“天马飞行”设置中改为保持当前视角，与念力出窍的视角设置互不影响。飞行期间手动切换视角后，落地不再强制切回。

体力容量为 1000，约为首版的十倍。加力逐渐增强，松开后逐渐减弱；耗尽后需要松开 W，恢复体力后再按。普通飞行和惯性滑翔仍可继续，快捷栏上方的短条显示剩余体力。

## 落地与碰撞

- 非滑翔坠落接近地面时拍翼减速，落地不重复结算旧的坠落距离。滑翔期间不触发这项保护。
- 滑翔正面撞上地形且速度足够时产生冲击波和范围伤害，随后团身回弹、展开并恢复悬停。擦碰不触发砸击；地形不被破坏。
- 撞击越快，伤害、冲击范围和震动越强；进入危险速度后自身也会受伤。
- 低速滑翔实际接触地面后结束飞行，恢复地面操作。空中速度较低不会自动切回悬停；滑翔落地仍按实际坠落情况处理伤害。
- 冲撞生物按双方相对接近速度计算伤害与击飞。近似同速、同向并飞不造成伤害；有效命中后减速，但继续飞行。
- 伤害遵守服务器 PvP 规则，并排除同队成员和自己的宠物。同一次接触不会连续重复结算。
- 不飞入未加载区块或越过世界边界；死亡、换维度、传送、改族及不适用的活动状态会清理飞行状态。

飞行风声、白色翼尖拖尾和附近撞击震动用于反馈速度与冲击。风声音量、飞行及撞击震动可在玩法包的“天马飞行”设置中减弱或关闭。

## 实现边界

飞行运动、体力、碰撞与伤害由玩法服务器结算，客户端预测并校正位置。外观包通过公共 API 1.6 接收飞行姿态，负责模型转向、拍翼和团身；原有模型、UV 与动画文件保留。此测试版需要配套外观包 0.3.6 或兼容新版。

彩虹音爆、音爆前即死速度段、突破后的撞地免伤均未启用，留待确定触发条件后制作。气流托举、尾流领航和天气互动同样属于后续方向。

## 验收重点

先在空旷处检查悬停时头身转向、起飞／落地视角和模式记忆，再测试持续加力、回环与横滚。生存模式检查非滑翔落地保护、低速滑翔落地和不同速度的撞击范围；在备份世界内测试墙面、低屋顶和半砖。

多人检查旁观姿态、同速并飞、碰撞伤害及不同距离的震动。第三方渲染与反作弊兼容仍需单独验证；自动检查不能代替这些实机项目。
