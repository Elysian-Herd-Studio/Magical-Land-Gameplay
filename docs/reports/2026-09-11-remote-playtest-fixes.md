# 出窍与托举试玩修复

日期：2026-09-11。下文记录修复完成时的独立检查。随后已构建并启动测试版，用户同意提交本轮改动；多人和兼容性验证继续保留。

## 本轮调整

- **精神回声**：轮廓扫亮后用约 3 秒渐淡，接到下一轮脉冲。旧波仍从原来的发射点计算，换轮保留远侧余辉，重合处不叠加变亮；每 3 秒发波、8 格范围与约 0.7 秒传播保持不变。
- **光学连接**：没有碰撞体积的草、花、甘蔗等装饰植物不再造成黑边。实体墙、地板和有碰撞的植物继续遮挡，飞行碰撞与交互射线仍各自检查。
- **动物互动**：选中货仓里的食物后，对应动物会追随光团，普通玩家手持食物的吸引优先。右键按原版规则喂养，并从选中槽处理消耗；回航光团不吸引动物，也不执行喂食或其他交互。牛羊等动物，以及使用 Brain 行为系统的山羊、骆驼、美西螈和青蛙均已接入。
- **普通物品攻击**：非工具物品左键攻击按原版空手伤害的一半计算；空槽不能攻击。工具和武器保留已有规则。
- **菜单与切屏**：Esc 打开菜单或切换窗口时保留出窍会话，暂停输入并清理排队的动作。出窍期间禁用本体背包，返回本体后恢复。

## 托举误停

Shift 松开前后，输入包与位移包可能错开约两刻。角色还带着上一状态的惯性，服务端却已按新状态估算速度，因而把正常移动误判为超速并停止能力。

本轮为这类时序差保留固定的位移余量，切键、停稳或收包都不会反复补发这份余量。异常位移、非法数值和过量发包校验继续保留。

根据后续确认，小幅超限也不再立即关闭技能：先回到服务端确认的位置，同时保留技能开启、落地保护、视角与合法惯性。两秒内前三次轻微纠正保留能力，第四次按持续异常处理；明显超限仍触发保护。纠正不放行穿墙，也不重新补发位移额度。

## 已确认的独立检查

- 精神回声的 CPU 时序测试通过，覆盖 3 秒渐淡、旧发射点与换轮衔接。严格 OpenGL 3.2 和原生扩展的离屏 GPU 检查均通过，包含双波残影、不叠加增亮、纹理隔离、深度与 alpha 保全及渲染状态恢复。
- Brain 动物吸引完成 1,939 项实际关联代码与源码边界检查，覆盖普通玩家优先、按动物区分食物，以及换槽、回航、遮挡、超距、掉线、死亡和换世界后的清理。测试使用简化世界对象，不能代替游戏中的动物寻路与繁殖验收。
- 普通诱食 Goal 的中途接管完成 301 项回归，避免动物已跟随光团时不能转向普通玩家。喂食与攻击回调后均再次检查会话和目标；136 项源码及原版字节码检查通过。
- 125 份 Gameplay 源码在仅引用外观公共 API 的条件下通过类型检查。真实 Minecraft 类转换涵盖诱食 Goal/Brain、菜单输入、移动校验和回声渲染；336 项遮挡检查与 59 项物品属性检查通过。
- 出窍输入门控 10,541 项、托举移动预算 121,117 项及轻微超速纠正 6,272 项独立检查通过。包含菜单动作积压、恢复操作、输入与位移错帧、反复切换 Shift、有限纠正和持续异常拒绝。

入口见[回声测试](../../tests/echo/README.md)和[动物吸引测试](../../tests/remote-temptation/README.md)。以上数字来自独立检查，不代表下方所有场景均已实机通过。

## 新包验收重点

观察回声换轮是否连贯、穿过草丛是否仍误黑；核对喂食数量和动物追随目标，检查切换物品及回航后能否及时停止吸引。另需复测菜单与切屏恢复、空槽和普通物品攻击，以及托举时反复按放 Shift、转向和减速是否还会误停。多人和网络延迟下的表现仍待实际检查。
