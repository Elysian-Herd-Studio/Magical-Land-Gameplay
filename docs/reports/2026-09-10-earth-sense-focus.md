# 专注感知与模糊色团检查记录

日期：2026-09-10。版本：Gameplay 0.3.2，Magical Land 0.3.4 / API 1.4。

## 本轮修改

此阶段采用模糊色团和站定下蹲专注，移动、跳跃或打开界面退出；新增灰白微模糊视野与环境闷声。慢蹲移动为[后续修订](2026-09-10-earth-sense-moving.md)。

红、黄、绿、蓝分别表示敌对、中立、友善生物和玩家。每只目标独立生成粗略色团，活动增强时更明显，静止后逐渐变淡。消息更新为带粗略位置与体型的 v2；14 格范围、种族校验和地面连通预算继续保留。

源码修改集中在 Gameplay。外观包、玩家预设、音量设置和存档格式未调整。

## 低饱和滤镜未显示的原因

0.3.1 实机日志记录了 `OpenGL 3.3 unavailable`。此前显卡测试使用 3.3 上下文，没有覆盖 Minecraft 实际使用的 3.2 上下文；滤镜因此进入降级路径。

本轮改用 3.2 兼容实现，仅在相关扩展和函数可用时使用采样器对象。实际 3.2 上下文的有／无采样器扩展路径均通过测试。

- 服务端：站定、受伤、地面连通、v2 消息边界、匿名短号、量化、目标替换与预算。修正原版旧攻击者记录过期可能被误判为新受伤的问题。

- 设置：灰白、模糊、闷声独立保存，保留未知配置，失败不覆盖旧值，中英文小窗口布局检查通过。
- 渲染：逐像素检查去饱和、微模糊、四色软边、深度与透明度保留，并检查状态恢复和跨会话清理。没有使用精确模型或客户端实体扫描。

这些验证不代替游戏内观感与多人验收。当时未记录色团投影位置、音效舒适度及第三方渲染／声音组合的实机确认结果。
