## 改动范围

- 会话、输入协议、库存、遮挡规则、动作上下文与客户端显示分离。v2 通道绑定请求、会话、实体和序号，迟到消息不能重新接管已结束的会话。
- 工具从本体真实转入独立库存。初始 1 槽、每槽最多 8 个，仍遵守物品自身上限；支持管理员测试解锁 1–9 槽，客户端用原版式快捷栏、滚轮和数字键选择。
- 攻击、采矿、工具使用、冷却和耐久通过作用域访问远控选中物品，保留本体身份及事件权限。视听反馈仍从投影发出。
- 第一人称接入挥动、换物和采矿循环，第三人称通过外观公共 API 使用投影独立惯性；避免与本体收放路径重复位移。
- 遮挡使用朝向本体的 25 点采样盘，半径 0.75 格、直径 1.5 格。独立于光团视觉与 0.3 格碰撞尺寸。普通玻璃可视但仍有碰撞，遮光玻璃阻挡视线。
- 随遮挡比例从屏幕外缘渐黑；全遮挡时停止交互。继续沿进入遮挡的方向主动深入 0.75 格才召回；停留、转向、横移、后退与惯性独自滑行不触发该条件。范围、受伤等其他安全退出条件继续生效。
- 黑屏覆盖在 HUD 之前绘制，隐藏 HUD 不会去掉黑屏。召回在黑屏峰值切回本体；跨世界立即清理旧相机。

玩法使用外观公开 API 编译，未复制外观实现。光效美术替换、无翼角色悬浮姿势、独角兽全身光晕仍是讨论方案。

## 本轮检查中修正的事项

- 静止投影突然被门等环境完全遮挡时，补充身体到投影的方向作为深入判定备用轴。
- 第一人称不再同时套用原版换物升降和本体侧边飞入路径。
- 采矿期间右键使用工具后，持续左键能重新进入采矿动作。
- 冷却条使用投影的权威冷却，避免显示本体的另一套状态。
- 跨世界返回清理先于淡出处理；全黑补满采用有限时长，避免比深入召回更迟。

库存与方块测试在 Fabric 类加载器下运行，以应用 Minecraft 包访问修正。修正射线夹具的空实体与旧彩蛋测试路径后，上述检查全部通过。

当时未覆盖各视角持物姿态、方块与战斗交互、渐黑手感、多槽切换及占用保护，以及返回、满包、工具损坏、死亡与 keepInventory、断线重进后的物品守恒实测。双客户端与网络延迟、失焦和换维度、渲染／领地模组兼容，以及正式 Loom 构建、发布 JAR 重映射、普通启动器安装和仅外观模式也未验证。

玩家数据与世界 PersistentState 的崩溃保存仍没有跨文件原子性保证；正常结算和旧格式恢复的测试不等于断电恢复承诺。特殊物品的使用范围见[出窍说明](../remote-presence.md)。
