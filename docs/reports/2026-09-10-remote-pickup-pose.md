# 出窍物品朝向与重新拾取修复

日期：2026-09-10。针对 Gameplay 0.2.1 试玩反馈，以下修订已构建并通过体验验收。

## 调整

- 剑、镐等工具静止时斜向上约 45°；视角俯仰仅小幅影响它，避免低头时又平躺或朝下。挥动动作继续保留。
- 普通平面物品采用原版飞行物的镜头朝向规则，像素画面正立、不镜像。方块等立体物品保持完整立体模型和竖直姿态。
- 读取当前物品模型的显示旋转并抵消，兼顾左右手；不改显示平移、尺寸及已有漂浮、拖尾参数。
- 修复出窍时无法捡回自己丢出的物品。原版 `ItemEntity.getOwner()` 返回投掷者实体，旧代码却拿它和玩家 UUID 比较。现在用只读 Mixin accessor 获取真正的拾取归属 UUID，分别处理投掷者与拾取权限。
- 保留丢物后 40 tick（约 2 秒）的拾取延迟、8 件容量、物品归属和障碍物检查。拾取射线对准掉落物碰撞箱中心；成功转入的数量才从世界扣除。

这轮只修改 Gameplay，外观包及其公共 API 不变。
