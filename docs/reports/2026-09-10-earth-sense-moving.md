# 震动感知：慢蹲移动与进退节奏

## 本轮调整

用户希望保留下蹲，移动比普通蹲行略慢，并避免被生物轻推就结束能力。

- 感知时可移动，平地速度约为普通蹲行的 80%。首刻补齐原版潜行系数，后续不重复减速；跳跃会结束感知并继续起跳。
- 无伤水平轻推不退出。实际受伤、离地、骑乘、换族、换维度、断线或打开界面仍清理专注状态，原版碰撞与击退保留。
- 服务器逐刻观察实际水平位移。静止范围 14 格，约 0.05 格/tick 时降至 6 格，更快位移最低 4 格；两刻内变弱，站稳后最多十刻恢复。地面搜索从当前脚下开始。
- 客户端额外淡化移动中的色团；目标自身活动强度仍表示目标制造的动静，不混入使用者速度。滤镜、FOV、鼠标调整与环境闷声保持专注，不随步伐反复开关。
- 入场改为 9 tick 的先快后慢曲线，退出为 5 tick 平滑曲线，中途切换从当前强度继续。20 TPS 下约为 0.45 / 0.25 秒，是本轮试调参数，不是《最后生还者 第二部》的实测值。

## 外观包配套

仅主动作控制器的移动蹲行动画 `sneak` 随实际步速放慢；静止蹲姿 `sneaking`、其他动作、眨眼、表情、耳朵和编辑器预览保持原速。依据原版 limbAnimator 的实际位移，不新增 Gameplay 专用接口或网络字段，远端玩家也沿用同一规则。

GeckoLib 4.8.3 直接改变动画倍率会重新缩放已播放时间，因此使用主控制器的连续局部时钟。速度变化只影响后续推进，不重新计算已经播放的进度；原循环、停止与切换仍交给 Gecko 处理。原动画资源不变。

## 检查范围

- Gameplay 全部 96 个 Java 源文件以 Java 17、仅依赖外观公共 API 的方式完成类型检查。
- 九组服务端核心回归通过，覆盖移动衰减、接地、受伤、会话、消息与原有地面搜索预算。
- 客户端输入、过渡曲线、信号质量、会话、能力轮盘及声音生命周期回归通过。
- 真实 OpenGL 3.2 的滤镜与色团回归通过，包括可选采样器启用／禁用路径；移动质量只作用于色团透明度。
- 外观控制器使用真实 Gecko 类验证动态减速、同帧重复处理、循环、切换、停止和恢复，并对两处生产类完成 Java 17 类型检查。
- 仓库边界、远控接入与中英文提示布局检查通过。

结果分别保存在工作区 `work/sense-moving-tests-20260910`、`work/sense-mobile-client-20260910`、`work/sense-moving-integration-20260910`、`work/sense-moving-render-20260910` 和 `work/earth-sense-20260910/sneak-animation-tests`。

独立检查后，按用户要求在 `work/sense-moving-game-20260910` 完成双包 Gradle 构建：Appearance `0.3.4+sense-moving-test-20260910` 与 Gameplay `0.3.2`。备份存档、配置和音量设置后，以同一测试世界启动；333 个快照文件与两仓当时源码逐项核对一致，原有六个音效未改变。

用户已确认这部分体验验收通过并同意推送。多人移动、不同地形及第三方组合仍保留专项验证，不以这次体验确认代替全部兼容测试。随后要求的第一人称专用飞行光罩限制见外观包报告；新的独角兽悬浮能力仍在讨论，本次未实现。
