# 自我悬浮：空中续按与视角纠正

记录日期：2026-09-11。现行规则见[自我悬浮](../unicorn-levitation.md)。以下保留当时修复与独立检查的范围。

试玩发现，上升时反复松开、重按跳跃键，可能让视角归零并关闭技能。重按等待确认期间，客户端仍按重力下落，而服务端已按上升检查位移，容易触发纠正；纠正又错误地把目标角度传成了零。短时间内反复纠正会被判定为持续异常移动。

修订后，同次已确认的空中施法可以立即续按；落地、关闭或会话失效后仍需重新确认。松开时同步清除旧移动预算与充能状态。位置纠正保留当前角度，正常释放时的惯性、地面长按门槛和异常移动检查均保留。

专项 Java 检查通过：包含 96 组各 400 刻的松按与延迟确认轨迹、落地后重新充能，以及执行原版传送方法的视角回归。新增续按测试可复现旧代码故障。此次独立检查时尚未重新打包或实机验收，当时已导出的 JAR 不含这项修复。
