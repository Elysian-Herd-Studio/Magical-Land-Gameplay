# 自我悬浮：实现与独立验证

版本：Gameplay 0.3.3，Appearance 0.3.5 / API 1.5。状态：代码与独立检查完成，尚未构建本轮游戏测试版，也未完成实机验收。

后续说明（2026-09-11）：这份报告记录初版检查时的状态。随后已构建并启动联合测试，用户发现移动误退出、Shift 下蹲、保护衔接及坠落伤害等问题；独立检查未覆盖这些真实操作路径。修订版暂停魔力限制并开放创造模式，进展见[修订记录](2026-09-11-levitation-controls.md)。下文的初版结果和魔力设计保留作历史记录。

## 本轮内容

独角兽轮盘增加「自我悬浮」。V 准备，地面长按跳跃键开始托举；空中重新按住时先按现有速度减缓下坠，再继续上升。松键停止主动加力，保留惯性。自动落地缓冲与液面悬浮先全部开放，成长等级后续分配。详细操作与试验魔力数值见[能力说明](../unicorn-levitation.md)。

玩法服务端负责身份、会话、魔力和有界移动校验，客户端使用同一运动计算进行带碰撞的移动。外观包增加纯视觉飞行注册，复用原有姿态、角光、包身光与声音；不修改飞行权限、模型或动画资源。第一人称边缘光罩限制继续保留。

## 检查结果

- 两仓真实 Java 17 目标源码检查通过：外观 148 个源码，玩法 109 个源码。玩法只用独立公共 API 编译，不依赖外观内部类。
- 公共 API 行为、独立消费者编译及包边界通过；新增飞行覆盖支持按玩家查询、撤销、异常隔离与断线清理。
- 运动与地形 7,288 项检查通过。使用真实 Minecraft 方块状态、碰撞形状与液面高度，覆盖半砖、围栏、流动水、岩浆、墙体遮挡、岸边过渡、未加载区域及查询预算。
- 服务端 5,344 项规则、移动预算、协议、存档与注入位置检查通过。预算按共享运动规则补充，不随客户端上报速度自行放大；正常延迟批次有有限余量，持续超速会被拒绝。
- 悬浮客户端 161,226 项会话／输入检查及 27 项接入检查通过；覆盖松键后旧确认、快速重按、换维度、恢复魔力和转向角跨界。
- 原有能力轮盘、种族、震动感知、飞行姿态与第一人称光罩回归通过。

地形检查通过 Fabric Knot 初始化依赖与注册表，但没有进入 Minecraft 主循环。源码、字节码和独立算法检查不等于游戏内验收，也不能代替第三方反作弊兼容测试。

## 检查中修正的问题

- 地面短跳途中离地曾会绕过长按门槛，现按本次按键开始时的状态计算。
- 液面目标增加约 0.15 格净空，并提前检测岸边可达液面。
- 落地制动改用离散游戏刻的速度上限，避免末刻仍下落过快。
- 修复受伤后旧血量基线导致无法重用、远端玩家清空本地预测，以及回魔消息不断重置冷却。
- 悬浮移动不设置原版飞行、无敌或穿墙标记。快速撞地仍保留摔落伤害。

## 后续验收

检查不同高度和坠速的起飞／落地、顶到天花板、转向惯性、水与岩浆边缘、魔力耗尽、多人同步和实际网络延迟。首次试验使用可恢复的测试世界；自动保护不能保证任何速度下都免伤。

独立入口：`tests/levitation/run-math-tests.ps1`、`tests/levitation/run-server-tests.ps1`、`tests/levitation-client/run-tests.ps1`。前两者接收依赖路径清单与仓库外输出目录，客户端入口接收同样用途的 `Dependencies` 与 `OutputRoot` 参数。它们不调用 Gradle 或启动游戏。
