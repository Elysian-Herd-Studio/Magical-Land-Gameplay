# 悬浮开关、保护与惯性修订

日期：2026-09-11。根据第二轮试玩反馈与后续确认修改，尚未重新构建或实机验收。

## 本轮规则

- 技能开启期间免疫摔落伤害；关闭后恢复原版规则。没有清空落距、开启通用无敌或屏蔽其他伤害。
- 落地缓冲和液面悬浮只在技能开启期间工作。松开空格保留开关，按 V 才关闭保护。
- Shift 用约八个游戏刻收住正常上升速度；下落时先按 Shift 再按空格，仍会先制动、略微向上托举，然后定高。
- 所有受控悬浮状态禁用冲刺；仅开启开关、仍在地面时不限制普通冲刺。
- 切屏、背包和能力轮盘保留开关。界面中不读取动作键，自动保护保持；单人暂停冻结本地会话时钟。

## 原因与处理

此前摔落保护依赖连续低速采样。慢速位移合并发送或落地包先到时，视觉上已经减速，服务端仍可能按累计下落距离扣血。按用户最终确定的规则，删除旧采样保护类，在原版玩家摔落伤害入口检查有效的独角兽悬浮开关。普通碰撞和落地过程仍然执行。

原先 HOVER 用上升加速度刹停，正常速度两刻即归零，看起来接近硬停。现改为较缓的收速，并增加 RECOVER 阶段，避免 Shift 优先按下时跳过回托。

连续模式切换回归另外发现：移动额度按上一刻预测补给，新的缓停过程会逐次消耗固定容差。改为按当前实际计算步长补给，保留有限预借与超速拒绝。

客户端与服务器均去掉“界面打开即结束”的条件；退出游戏、身份改变、骑乘、受其他伤害等仍按原规则清理。原轮盘入口中对悬浮的强制停止也已去掉。

协议升级为 v3，需要客户端与服务器一起更新。旧测试窗口不包含本轮规则。

## 检查与待验收

独立检查覆盖输入、有限加速度、先 Shift 后空格、液面跨格、开关保护、长时间移动及反复切换的收包顺序。全部玩法源码通过仅依赖外观公共 API 的 Java 17 编译检查。

真实 Minecraft 类加载检查覆盖玩家摔伤入口、移动校验、键盘输入与禁冲刺注入。未启动新的游戏窗口，没有替换运行中的游戏，也未提交或推送。

还需玩家验收：不同高度开关免伤、连续 Shift 切换、保持按键切屏、单人暂停与多人背包、液面和地面交界。多人网络延迟与第三方反作弊需另行验证。
