# 出窍验收反馈修复

日期：2026-09-10。开发版本：Gameplay 0.2.1、外观 0.3.2、公共 API 1.2。

根据 0.2.0 试玩反馈修订，独立检查与双包构建完成；本记录未包含视觉和操作效果的实机验收结果。

## 修改

| 反馈 | 原因与处理 |
| --- | --- |
| 远控缺少丢物操作 | 接入原版可改绑丢弃键：Q 丢一个，Ctrl+Q 丢整栈。服务端校验会话、序号、槽位、遮挡和生成位置，成功生成后才扣除远控库存；掉落物设 2 秒拾取延迟。 |
| 出窍时角不亮 | 原来的亮角条件依赖本体持物，工具转入远控库存后条件失效。新增可撤回施法活动 API，由远控实体维护，空手出窍也亮角；退出和断线清理。 |
| 第三人称方向不对，移动时抽搐 | 惯性锚点原先用相机四元数反推，与实际世界渲染矩阵不一致。改用当帧真实矩阵，工具朝前并略侧转，挥动不再移动弹簧锚点，观察者收到的方向沿最短角度插值。保留漂浮惯性。 |
| 贴近平整地面也触发黑边 | 放大的虚拟采样点伸进地板，被当作本体视线受阻。先把采样点截在光团所在一侧的实际表面前，再检查本体视线。保留 0.75 格采样半径及真实隔墙遮挡。 |

外观包只增加通用施法活动接口和修正世界持物渲染；Gameplay 继续通过公开 API 使用它们。普通本体持物、第一人称收放及捏脸预览的原有路径保持不变。
