# 自我悬浮：首轮试玩修订

后续试玩仍有保护漏判，规则改为技能开启期间免疫摔伤，并调整输入与界面行为，见[后续修订](2026-09-11-levitation-protection.md)。以下保留此阶段的检查记录。

日期：2026-09-11。对象：Gameplay 0.3.3 / Magical Land 0.3.5，分别覆盖 `a23da8c`、`5724bdf` 后的工作区修改，接续[初版独立检查](2026-09-10-unicorn-levitation.md)。

## 用户反馈与修订

| 反馈 | 原因与处理 |
| --- | --- |
| 普通方向移动会让能力退出，Shift 移动反而可以维持 | 移动包先到，服务器在 tick 结束时才补充移动额度。旧版静止时只有 0.12 格余量，普通起步第 5 帧的 0.125 格被误拒，Shift 的旧限速恰好避开了问题。修订处理收包顺序，并按共享运动规则核算有限的一刻提前量。 |
| Shift 进入下蹲，速度降低且镜头下移 | 原版潜行输入仍在生效。修订将原始按键用于施法，在充能时单独屏蔽潜行，实际托举时再接管跳跃；普通准备状态仍可正常下蹲。 |
| 魔力槽不停闪动 | 本轮按要求移除魔力槽、消耗与不足限制。旧存档字段保留，当前不再读写；协议保留常量占位，供以后统一魔力系统时处理。 |
| 创造模式不能测试 | 开放创造资格。V 准备时退出正在进行的原版飞行，保留飞行权限；结束后恢复原版飞行按键，不自动重新起飞。 |
| 开启能力后落地缓冲衔接异常，慢降落地仍受伤 | 主动托举和自动保护重新对齐；安全落地证明独立于当前模式，处理最后一个落地包晚于模式退出的情况。只有可信的实际减速才减免旧坠落记录，快速撞地仍受伤。 |
| 安全的小落差也触发缓冲 | 加入本次预计摔落是否危险的判定，不再仅因接近地面就启动。 |
| 液面移动容易失去支撑 | 补全前方液面探测与液面高低衔接，仍检查实体遮挡和深水。普通方向移动可持续悬浮，不要求先按 Shift。 |

上升时水平速度为 0.065 格/tick，约等于蹲行；Shift 定高与液面悬浮为 0.216 格/tick，约等于步行。模式切换渐进加减速，主动上升保持 0.16 格/tick。

## 验证

以下检查通过，均没有启动游戏主循环：

- 完整源码的 Java 17 目标检查：外观 158 个源码，Gameplay 112 个源码。Gameplay 仅使用外观公共 API 编译；两仓边界检查通过。
- 共享物理及真实方块/液面检查：覆盖安全小落差、危险坠落、Shift 有限制动、两档横移速度、连续水面/岩浆面移动、流水台阶、顶面遮挡及深水拒绝。
- 服务端规则与真实移动包：复现旧起步误拒，覆盖收包先于 tick 补给、延迟合批、模式切换后的预测额度兑现、同刻多输入包以及持续超速拒绝。
- 落地交接：已确认的慢降可以跨越模式退出；没有新移动包的停顿不计为减速，快速碰地不免伤。最后一个缓慢触地包可以完成已有慢降证明。
- 客户端会话及真实 `KeyboardInput.tick`：覆盖充能时 Shift 不蹲但短跳仍可用、实际施法接管跳跃、普通方向移动、单次物品减速、创造模式保留飞行权限及提示分支。挂点与原版输入先后关系通过字节码检查。
- 无窗口 Knot 类转换：服务器落地回调、移动包钩子，以及客户端 `KeyboardInput`、`ClientPlayerEntity` 的本轮必需注入均命中。加载检查发现继承字段不能在当前目标类直接声明 `@Shadow`，已改用正确的父类继承访问并复跑通过；单独编译和字节码存在性检查没有发现此问题。
- 种族、能力轮盘与陆马震动感知的会话、输入、视野及退出回归通过。

悬浮消息通道升级为 `_v2`，避免新客户端与旧开发服务器混用不同物理规则。协议中的旧魔力字段暂保留常量 100，不参与限制能力。

复跑入口：`tests/levitation/run-math-tests.ps1`、`tests/levitation/run-server-tests.ps1`、`tests/levitation-client/run-tests.ps1`、`tests/race/run-tests.ps1` 与 `tests/sense-client/run-tests.ps1`。使用绝对依赖清单路径和仓库外输出目录；完整无窗口转换环境与日志保存在本地工作目录，不进入模组资源。

测试重点从单独公式扩展到按键、收包和落地的先后顺序。纯逻辑和源码检查通过，不代表已完成游戏听感、镜头或真实多人验收。
