# 种族核心能力设计草案

记录日期：2026-09-09。

分类：[三族能力](README.md#三族能力)。状态更新于 2026-09-10：本文保留三族核心玩法的设计方向。独角兽念力出窍已有可测试实现，陆马基础震动感知本轮接入；当前功能见各族说明。其余能力、消耗与成长按下述草案逐步开发，具体数值和部分规则待定。

2026-09-11 补充：采用“先开发并开放完整功能，再安排成长等级”的统一原则。本文下方“基础阶段/后期升级”和推荐顺序保留为早期草案。独角兽最新约定以[完整功能开发方案](unicorn-ability-plan.md)为准：本轮出窍开放 9 槽、原版堆叠、128 格范围和精神回声，取消全遮挡后主动深入导致的强制退出，并接入携物回航；瞄准标记、照明和统一御物指令仍待实现。陆马感知和悬浮已实现的功能全部开放，矿物感知等扩展列入后续计划。

## 总体方向

- 外观与玩法由两个独立仓库维护；Gameplay 通过公共 API 使用通用外观表现，负责三族能力规则与成就系统，见[仓库边界](repository-boundary.md)。
- 能力应服务探索、建造、采集等日常活动，而不只提供战斗数值。
- 各族以不同方式解决问题，避免独角兽完全替代其他种族的核心优势。

## 独角兽：念力附着与远程操控

### 核心体验

后续确认补充：允许空手出窍，第三人称表现为复用现有魔法光效的光团，可拾物并操作门、拉杆等；仅持物发动才携带主手物品，工具/武器提供远程使用。自由飞行类似观察者操作但有碰撞，不实际切换观察者模式。

独角兽集中精神，将感知附着于一个物品；本体留在原地，玩家切换到物品附近的视角，控制物品飞行、探路和使用工具。与不切换视角的工具指令模式共用魔法值和控制容量。

### 模式一：附着操控

- 玩家亲自控制一个物品的飞行与操作；基础阶段只能控制一个物品。
- 本体眼睛到物品之间需要无遮挡，并受到最大控制距离限制。具体距离、速度和消耗待实测确定。
- 物品视角正常受场景遮挡；连接能力不等于透视，也不允许物品穿墙。
- 本体在合理转头范围内朝向物品；不要把本体原先屏幕朝向误当成固定的连接方向限制。
- 接近连接限制时先减弱光效、压暗画面边缘；短暂遮挡有容错，持续失联后退出附着并召回，避免反复闪黑或停留在黑屏。
- 附着时本体站定、保留施法表现；玩家可主动退出，受伤时警告并自动退出。
- 后期可成长为有限厚度的隔墙连接；此能力不授予穿墙移动或直接观察隐藏矿物的权限。

### 模式二：指定工具采集

以下采集条件为用户明确补充，应优先于泛化的自动采矿设想。

- 只有玩家当前看得见目标矿物、视线无遮挡时，才能指定工具飞过去采集；按本体视角验证，不能借附着镜头绕过这一指令模式的限制。
- 基础阶段只采集玩家明确指定的那一块，完成后工具自动返回；不自行寻找或继续采集相邻矿物。
- 工具必须有可达路径和可操作位置；视线无遮挡不自动代表体积和路径可达。路径被挡时提示失败或返回，不擅自拆除障碍。
- 使用玩家原有工具，遵守工具等级、耐久、附魔、方块硬度和服务器权限。
- 基础阶段掉落物正常落地，不自动送进背包。
- 后期升级可自动采集与目标连接的其他矿物，并自动将掉落物带回背包。
- 连矿升级仍需先指定可见且无遮挡的起始矿物；邻接规则、矿物种类匹配、最大块数、遮挡后的采掘方式、路径和距离上限待后续设计，不默认为无限透视搜索或穿墙采矿。
- 后期自动收集需明确背包满时的处理方式，不允许吞掉或复制掉落物。

### 魔法值与成长

- 悬浮有较低维持消耗；距离、工具动作、多物品负载及进阶隔墙连接分别增加消耗。
- 低魔力提前提示；耗尽时停止任务、退出附着，并保障安全召回，不因无魔力遗失工具。
- 成长方向包括感知（距离与连接稳定性）、精控（精细操作和任务能力）、负载（携带资源与更多物品）。
- 多物品阶段仍只附着控制其中一个，其余跟随或执行已下达任务；不引入多个同时操控的镜头。
- 更多工具不默认按数量倍增单块挖掘速度。

### 安全与多人边界

- 服务端验证目标、距离、遮挡、消耗、耐久、采掘权限和物品归属，客户端不能自行决定采矿结果。
- 不加载无限远区块、不无限扫描矿脉；限制方块数量、实体数量和每次处理预算。
- 退出、死亡、断线、换维度、区块卸载时有明确终止和工具归还规则，防止复制、遗失或残留悬浮物。
- 基础阶段不包含自动搬运其他玩家或无限无人值守采矿。

### 推荐实现顺序

1. 单物品附着飞行、连接限制、退出与安全召回。
2. 本体可见且无遮挡的单块采集指令、魔力与工具规则。
3. 多人和异常生命周期验证。
4. 再设计成长、多物品、有限隔墙连接、连矿采集和掉落物回收。

## 天马：飞行与气流操控

2026-09-13 更新：飞行首版已接入，等待实机验收；按键与当前规则见[天马飞行](pegasus-flight.md)。砸击由速度与实际碰撞触发，当前按完整能力开放，后续再接天赋树。以下保留设计方向；彩虹音爆暂缓制作。

### 核心体验与操作划分

- 基础飞行直接可用，成长拓展技巧与辅助能力，不将基本飞行锁在漫长升级之后。
- 保留普通飞行与悬停，另有带惯性的滑翔。俯冲获得速度，抬头以速度换取高度；滑翔时可以拍翼加力，体力用于限制加力。
- 飞行姿态设限制开关。解除后允许完整俯仰回环和横滚，玩家可以自行完成大回环，再俯冲接砸击。操控开关与未来的成长解锁条件分别设计。
- 双击空格起飞／结束飞行，Ctrl 切换普通飞行与滑翔，Tab 切换滑翔姿态锁定与特技操控。滑翔时 W 加力、S 减速；解锁姿态后 A／D 横滚。普通飞行保持 WASD 平移、空格上升和 Shift 下降。
- 高速时增加风声、屏幕震动和第三人称拖尾。普通高速反馈与后续彩虹音爆分别制作，具体强度待验收。

### 拍翼落地保护

- 普通坠落接近地面时自动拍翼缓冲，表现参照独角兽的落地托举，改用翅膀完成减速。
- 只要处于滑翔模式，就不触发落地保护；是否主动俯冲、是否达到砸击速度都不改变这条规则。
- 成功缓冲后接普通落地动作，并正确结算本次坠落，避免平稳落地后仍因旧的累计坠落距离再次受伤。触发高度、制动力与消耗细节待定。

### 地形砸击与回弹

- 点出对应天赋后，达到速度门槛并真正撞上地面或墙壁就触发。无需按技能键准备，也不标记目标或落点；速度由玩家自己的飞行操作获得。
- 擦碰不触发。伤害随实际撞击速度增加，过快时自身也会受伤；具体起效速度、危险速度、伤害曲线和上限待定。
- 地形命中产生范围伤害和冲击波，再回弹到空中，最后恢复悬停。回弹高度根据撞击与周围空间设计，不再固定回到原先的起飞或释放高度。
- 回弹表现复用高空坠落的团身姿势，去掉身体拉伸，旋转数圈后舒展并悬停。提取独立动作，保留原坠落动画；圈数、镜头跟随和提前接管方式待定。
- 砸地越快，屏幕震动越强。范围内所有玩家，包括发动者，都能感受到；距撞击点越远，震感越弱。震动范围、叠加上限与本地舒适度设置待定。
- 实施时区分撞击自伤与后续回弹，避免同一次撞击反复伤害或重复结算普通摔伤。液体、半砖、低屋顶、地形破坏及服务器权限规则仍需确定。

### 生物冲撞

- 真正撞上生物时造成伤害和击飞，擦碰不算。判定使用双方沿撞击方向的相对接近速度，而非只看天马自己的飞行速度。
- 两只飞马同向、近似同速并排飞行时，轻微接触不造成伤害。
- 命中后仅损失一部分速度，仍可继续飞行，不强制进入地形砸击的团身回弹。
- 减速比例、连续撞击不同生物、同一次接触的结算间隔，以及 PvP／队伍保护的具体规则待定。

### 彩虹音爆：暂缓制作

- 彩虹音爆暂列待办，待确定触发条件后再实现；成长方式、操作要求和速度阈值尚未定案。
- 已确认的风险设计：达到音爆前的一段危险速度区间时，撞上地面即死；成功突破彩虹音爆后，再撞地面有免伤。
- 实施时确认危险区的启用时机，以及突破后免伤的持续时间、维持条件和退出规则。撞墙、撞生物是否适用另行讨论；这项设想不等于对所有伤害永久免疫。

### 后续扩展方向

- 独立向前冲刺：保留为移动、追击和闪避方向，与滑翔加力的操作和消耗关系另议。
- 气流托举：在近距离指定位置制造短暂上升气流，用于登高、减缓坠落或将坑中的掉落物托起。其他玩家应主动进入或能够拒绝托举，避免强制位移。
- 掠地滑翔：俯冲接近地面时拉平，将下降速度转为水平速度，并可借惯性爬升；融入自然飞行操作。
- 尾流领航：持续定向飞行形成短暂尾流，为跟随的认可队友提供降低飞行消耗或稳定跟随的收益；不作为单人基础能力前提。
- 局部天气作业：聚拢小雨云浇灌或扑灭普通火焰、驱散局部云雾；后期考虑雷雨环境收集电荷并有限释放。初期不直接控制全世界天气，也不通过雨云瞬间催熟植物。
- 后期提升气流持续时间、承载能力及云朵互动。天气和尾流属于扩展方向，不作为首版全部必做项。

## 陆马：力量与大地共鸣

### 核心方向

- 强壮身体与通过蹄子传导的大地共鸣结合；表现以蹬地、奔跑、后踢及地表反馈为主，不复制独角兽的远程施法形式。
- 扎根蓄力：四蹄站稳，限制移动并提高抗击退能力，再释放力量。
- 强力后踢：对敌人击退、打断，对果树震落成熟果实而不破坏整树；保留动作前摇，不无限连踢。可朝目标发动，由动画处理转身、后踢和朝向恢复，具体镜头方案待验收。
- 自然共鸣：影响小范围作物生长，成熟作物不额外占用效果；后期考虑扩大范围、收获和补种。重复作用同一土地的收益限制待定，不默认无限催熟。
- 短距离冲撞与定向地面冲击为候选释放方式；首版建议择一，不视为已经确定全部实现。
- 推荐先完成扎根、后踢和自然共鸣；震动感知按下述阶段扩展。具体优先级可在开始实现前调整。

2026-09-10 更新：先实现基础震动感知，当前功能见[使用说明](earth-sense.md)。后踢和范围砸地等用户补充攻击动画后再做；自然共鸣与成长继续保留在后续计划中。

同日验收后确认：基础感知采用下蹲专注，显示模糊四色团，并加入低饱和、轻微模糊与闷声。随后按体验反馈允许慢蹲移动：速度略低于普通蹲行，动画配套放慢；移动时范围与信号明显减弱，站稳后恢复，无伤轻推不再退出。跳跃、受伤、离地或打开界面仍会打断。色团包含粗略位置与体型；更清楚的生物剪影和矿物方位仍属于后续成长。当前规则见[震动感知](earth-sense.md)。

### 震动感知：已确认的表现与成长

- 开启感知后，视野切换为低饱和、偏灰白的色调，突出地面震动信息。
- 基础阶段可以指出敌对生物和友好生物所在方向，以可区分的反馈表示两类目标。
- 玩家根据震动强弱估计距离，不直接提供精确距离数字。
- 升级后可看到生物的大致轮廓，并感知矿物的大致方位；不默认显示精确矿块坐标、完整矿脉或具体矿种。
- 此条更新此前“暂不感知矿物”的候选建议：矿物方位现已纳入后期成长方向。

### 震动感知：已确认的信号规则

- 距离决定基础信号强弱，动作决定波纹节奏；避免远处强壮目标仅因震动大而被误判为近处目标。
- 静止目标信号更弱，离地目标难以感知，能力依赖地面传播而非全方位实体雷达。
- 中立生物与其他玩家单独分类，不把陌生玩家自动判为敌人；方向提示同时使用不同形状，不能只靠颜色区分。
- 生物轮廓随震动短暂显现并消退，而非持续精确透视；高阶矿物方位通过主动踏地的共鸣回波提示。

### 震动感知：待定参数与实现建议

- 建议使用者接触地面才能感知；水中目标及短暂离地时的衰减和容错规则待定。
- 建议避免依赖屏幕抖动或声音才能读懂反馈，并保留降低灰白滤镜强度的选项。
- 检测范围、持续时间、消耗、升级条件、矿物类别与扫描频率待定。服务端限制扫描预算与信息下发，不扫描无限区域或加载远处区块，并考虑服务器禁用矿物感知的配置。
