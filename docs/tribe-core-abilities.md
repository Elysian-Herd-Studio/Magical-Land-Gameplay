# 三族核心能力规划

最初记录于 2026-09-09；2026-09-11 起采用先开放完整功能、再划分成长等级的开发顺序。

当前可用能力见[三族能力](README.md#三族能力)。本文记录后续玩法方向；独角兽最初的单物品与单块采集阶段见[早期方案归档](archive/2026-09-09-tribe-stages.md)。

## 总体方向

- 能力服务探索、建造、采集与战斗，各族用不同方式解决问题，保留各自优势。
- 基础能力先完整开放，成长再拓展技巧、负载和辅助效果；基本飞行直接可用。
- 玩法通过公共 API 使用通用外观表现，模块分工见[仓库边界](repository-boundary.md)。
- 目标、距离、权限、耐久、伤害和物品归属由服务端判定。扫描与寻路限定距离、数量、每次处理预算及已加载区块。
- 死亡、断线、换维度和异常卸载时按明确规则结束任务、归还携带物；正常与异常流程都需防止复制、遗失和残留实体。

## 独角兽：念力与精控

以留在本体旁的御物指令，以及切换至光团视角的附着操控，服务探路、交互、采集和护卫。当前已实现[念力出窍](remote-presence.md)、[御物](telekinesis.md)和[自我悬浮](unicorn-levitation.md)。

后续制作独角照明与定点魔法灯，再统一魔力和成长。距离、连接稳定性、精控与负载的具体安排见[独角兽能力规划](unicorn-ability-plan.md)。

## 天马：飞行与气流操控

[天马飞行](pegasus-flight.md)已提供普通飞行、惯性滑翔、拍翼加力、自由特技、落地保护及碰撞反馈。操控偏好与成长解锁分别管理；普通悬停、滑翔和回环的现行操作由该说明维护。

### 成长与砸击

- 后续将砸击接入天赋树。学会后，只要速度足够并真正撞上地面或墙壁就自动触发；沿用实际碰撞，不设置施放键或目标标点。
- 保留速度越快伤害越高、冲击范围与震动越强的方向，过快时自身也承担风险。擦碰不触发砸击。
- 砸击后团身旋转、回弹，再舒展悬停；回弹高度根据撞击与周围空间决定。姿态复用高空坠落的团身造型，保持正常身体比例。未来数值与成长等级一起平衡。
- 附近所有玩家都能感受冲击震动，距离越远越弱；继续保留本地舒适度设置。
- 拍翼落地保护用于普通坠落，滑翔时保持关闭。缓冲成功后接普通落地动作，完成本次坠落结算；解锁与消耗随成长系统划分。
- 冲撞生物按双方相对接近速度计算。命中后损失部分速度并继续飞行；同速同向并飞保持安全。地形砸击和生物冲撞分别结算，遵守 PvP、队伍与自家宠物保护。

### 彩虹音爆：暂缓制作

- 待确定触发条件后再实现，成长方式、操作要求和速度阈值尚未定案。
- 已确认的风险设计：达到音爆前的一段危险速度区间时，撞上地面即死；成功突破彩虹音爆后，再撞地面有免伤。
- 危险区启用时机，以及突破后免伤的持续时间、维持条件和退出规则仍需确定。撞墙与撞生物是否适用另议；免伤仅限对应撞击情形。
- 当前即死速度段和音爆免伤均未启用。

### 后续扩展方向

- 独立向前冲刺：用于移动、追击和闪避，与滑翔加力的操作和消耗关系另议。
- 气流托举：在近距离指定位置制造短暂上升气流，用于登高、减缓坠落或将坑中的掉落物托起。其他玩家可主动进入或拒绝托举。
- 掠地滑翔：俯冲接近地面时拉平，将下降速度转为水平速度，并借惯性爬升，融入自然飞行操作。
- 尾流领航：持续定向飞行形成短暂尾流，为跟随的认可队友降低消耗或稳定飞行；作为组队增益，单人基础飞行保持独立。
- 局部天气作业：聚拢小雨云浇灌或扑灭普通火焰、驱散局部云雾；后期考虑雷雨环境收集电荷并有限释放。作用范围限于局部，植物沿用正常生长节奏。
- 后期提升气流持续时间、承载能力及云朵互动。天气和尾流是扩展方向，开发次序另行安排。

## 陆马：力量与大地共鸣

强壮身体与通过蹄子传导的大地共鸣结合，动作以蹬地、奔跑、后踢及地表反馈为主。2026-09-10 调整为先制作[震动感知](earth-sense.md)，攻击能力等待配套动画。

### 待开发：力量与自然共鸣

- 扎根蓄力：四蹄站稳，限制移动并提高抗击退能力，再释放力量。
- 强力后踢：击退、打断敌人；震落果树的成熟果实并保留整树。保留动作前摇与出招间隔，可朝目标发动，由动画处理转身、后踢和朝向恢复；镜头方案待设计。
- 自然共鸣：影响小范围作物生长，成熟作物不额外占用效果；后期考虑扩大范围、收获和补种。同一土地重复受益的限制待定。
- 短距离冲撞与定向地面冲击均为候选释放方式，首版先选一种，尚未决定全部制作。

### 待开发：震动感知的进阶信息

当前感知使用低饱和画面、四色模糊团和闷声表达地面活动，规则与限制见[震动感知](earth-sense.md)。

- 生物的大致轮廓随震动短暂显现并消退；矿物方位通过主动踏地的共鸣回波提示。
- 玩家根据震动强弱估计距离。进阶矿物反馈只提供大致方位，保留对精确坐标、完整矿脉和具体矿种的信息限制。
- 距离决定基础强弱，活动决定清晰度与节奏；静止目标较弱，信号依赖地面传播。中立生物与玩家分别分类，陌生玩家不自动算作敌人。
- 早期提出过形状区分类别，当前采用四色模糊团，形状辅助仍待制作。视觉本身应能传达信号，继续保留滤镜强度选项。
- 成长、消耗、矿物类别与矿物扫描频率待定；保留有限扫描预算和信息下发，使用已加载区块。矿物感知的服务器开放规则一并设计。
