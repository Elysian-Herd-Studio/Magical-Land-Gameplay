# 「不是这个意思！」彩蛋

- 同一玩家在 15 秒内自己吃完金胡萝卜，并给成年普通马喂金胡萝卜、成功进入原版求偶状态，先后顺序不限。仅持有食物、普通胡萝卜或金苹果不触发。
- 保留 8 格范围、双方可见、正常配偶优先、单次触发与 5 分钟冷却；马有正常配偶时不抢占繁殖行为。
- 马靠近期间冒爱心，接触后沿用原有轻伤与安全击退保护，并授予「不是这个意思！」成就。
- 只有实际造成伤害后才调用原版 `playAngrySound()`，使用驯服失败时的扬蹄动作与声音；不改变驯服状态、不清除主人、不额外增加伤害或主动攻击 AI。
- 喂食/进食关联是短期状态，超时、断线、死亡或换维度后清理。该彩蛋全部位于玩法包。

顺序、超时、玩家/维度隔离、冷却和食物过滤有自动回归检查；扬蹄观感与实际触发仍需游戏内验收。
